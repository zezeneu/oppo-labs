# Работа 2 — рефакторинг (разбиение на функции), git

Открыть `Lab2.sln` в Visual Studio 2022, конфигурация Debug x64, запуск Ctrl+F5.
Вводите занятия по одному в строке, пустая строка завершает ввод, затем имя преподавателя для фильтра:
```
2024.03.11 14:30 "Иванов И.И."
```
Программа выводит занятия в порядке ввода, по возрастанию времени и отфильтрованные по преподавателю.
