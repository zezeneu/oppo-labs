# Работа 1 — Visual Studio 2022

## Как открыть
Дважды щёлкните `Lab1.sln` — откроется в Visual Studio 2022.

## Как собрать и запустить
1. Наверху выберите конфигурацию **Debug** и платформу **x64**.
2. Нажмите **F5** (или Ctrl+F5, чтобы окно консоли не закрывалось сразу) —
   VS сама скомпилирует и запустит программу.
3. Программа попросит ввести строку вида:
   ```
   2023.09.15 14:30 "Иванов Иван Иванович"
   ```

## Сборка из командной строки Windows (без открытия IDE)
Откройте **Developer Command Prompt for VS 2022** (есть в меню Пуск —
он автоматически настраивает пути к компилятору `cl.exe`) и выполните
в папке `Lab1`:

```bat
cd Lab1
chcp 65001
cl /EHsc /std:c++17 /utf-8 main.cpp /Fe:Lab1.exe
Lab1.exe
```

Флаг `/utf-8` нужен, чтобы кириллица в исходнике не превратилась в «кракозябры»,
`chcp 65001` переключает консоль в UTF-8. Флаг `/EHsc` включает обработку исключений, `/std:c++17` — нужный
стандарт языка .
