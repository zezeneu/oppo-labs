## Кириллица в консоли
Исходные файлы сохранены в UTF-8 с BOM, строки компилируются в Windows-1251 (`/source-charset:utf-8 /execution-charset:windows-1251`),
консоль переключается на Windows-1251 (`SetConsoleCP(1251)`, `SetConsoleOutputCP(1251)`). Поэтому вводите данные с клавиатуры
или из файла, сохранённого в кодировке **ANSI (Windows-1251)**: Блокнот → «Сохранить как» → кодировка «ANSI».
Если вы создаёте свой проект и копируете файлы, оставьте эти флаги (Свойства проекта → C/C++ → Командная строка).
